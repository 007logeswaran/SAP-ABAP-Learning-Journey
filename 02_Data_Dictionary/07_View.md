# View in SAP ABAP

## Definition

A View is a virtual table that combines data from one or more database tables without storing the data separately.

---

## Why do we use Views?

* Simplify data retrieval
* Combine multiple tables
* Improve readability

---

## Types of Views

* Database View
* Projection View
* Maintenance View
* Help View

---

## Real-Time Example

A View can combine **EKKO** (Purchase Order Header) and **EKPO** (Purchase Order Item) into a single logical view.

---

## Interview Questions

### What is a View?

A View is a virtual table created from one or more database tables.

### Does a View store data?

No. It displays data from underlying tables.

---

## Common Mistakes

* Assuming Views store data.
* Using unnecessary tables in a View.

---

## Best Practice

Use Views to simplify complex database access.

---

## Summary

Views combine data from one or more tables without storing it separately.
