# SAP ABAP Data Dictionary

## Overview

The ABAP Data Dictionary (DDIC) is used to define and manage database objects in SAP. It provides a centralized repository for tables, structures, data elements, domains, views, search helps, and lock objects.

## Topics Covered

* Domain
* Data Element
* Database Table
* Structure
* Search Help
* Lock Object
* View
* Table Maintenance Generator
* Foreign Key

## Goal

To understand the foundation of SAP database design and how ABAP programs use Data Dictionary objects.
